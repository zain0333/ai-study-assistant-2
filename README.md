\# AI Study Assistant 2.0



AI Study Assistant 2.0 is a simple AI-powered study application designed to help students ask questions and get useful answers from their study material.



\## Features



\* Ask study-related questions

\* Get AI-generated answers

\* Use uploaded study material

\* Store study history

\* Upload documents

\* Backend API for communication

\* GitHub-based project version control

\## How It Works



```text

User

&#x20; ↓

Frontend

&#x20; ↓

API Gateway

&#x20; ↓

AWS Lambda

&#x20; ↓

AI Model

&#x20; ↓

Response

```



The application receives a question from the user. The backend processes the request and sends it to the AI model. The generated answer is then returned to the user.



\## Project Goal



The goal of this project is to build a simple and useful AI study assistant that can help students understand their study material more easily.
